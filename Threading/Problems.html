01 Single-topic FIFO

Write a class Queue1 with:

  • publish(msg: str) -> None
  • consume() -> str | None — oldest unread message, or None if empty.

Example

q = Queue1()
q.publish("a"); q.publish("b"); q.publish("c")
q.consume()  # → "a"
q.consume()  # → "b"
q.consume()  # → "c"
q.consume()  # → None
Self-check: three consumes return "a", "b", "c", then None.

02 Multi-topic routing

Write Queue2 with publish(topic, msg) and consume(topic). Topics are independent FIFOs. A topic never published to returns None — don't raise.

Example

q = Queue2()
q.publish("a", "1"); q.publish("b", "2"); q.publish("a", "3")
q.consume("a")  # → "1"
q.consume("a")  # → "3"
q.consume("b")  # → "2"
q.consume("c")  # → None  (never published)
Self-check: per-topic order is preserved and unknown topics are safe.

04 Per-topic locks

Refactor into Queue4. One _topics_lock guards only the dict[str, TopicState]. Each TopicState owns a Lock around its own deque.

Rule: never hold both at once. Get in, look up or create, get out, then lock the topic.

Example — the lookup pattern

def publish(self, topic, msg):
    with self._topics_lock:                        # short: dict access only
        state = self._topics.setdefault(topic, TopicState())
    with state.lock:                               # then: the real work
        state.deque.append(msg)
Self-check: step-3 harness still clean. Read your code back — no method holds both locks simultaneously.

05 Message objects

Introduce a Message dataclass. publish returns the new id; consume returns the whole Message.

Example

@dataclass
class Message:
    id: str
    payload: str
    enqueued_at: float

q = Queue5()
msg_id = q.publish("t", "hello")   # → "3f8a…c1"
m = q.consume("t")                 # → Message(id="3f8a…c1", payload="hello", …)
assert m.id == msg_id and m.payload == "hello"
Self-check: ids are unique per publish; enqueued_at comes from time.monotonic(), never time.time().

06 Lazy TTL

publish(topic, payload, ttl_s) stores expires_at = enqueued_at + ttl_s. On consume: pop from the head; if monotonic() >= expires_at, discard and keep going; return the first live one.

Example

q = Queue6()
q.publish("t", "a", ttl_s=0.1)
q.publish("t", "b", ttl_s=10)
time.sleep(0.2)
q.consume("t").payload   # → "b"   ("a" silently dropped)
q.consume("t")           # → None
Self-check: the expired head is skipped, not returned; the deque ends up empty afterwards.

07 Eager reaper

Add a daemon thread that wakes every 100 ms and, per topic, walks the entire deque under that topic's lock, removing expired messages. Add close() that stops it cleanly — threading.Event, never signal.alarm.

Example

q = Queue7()
for i in range(100):
    q.publish("x", f"m{i}", ttl_s=0.1)
time.sleep(0.5)                        # reaper wakes ~5 times
assert len(q._topics["x"].deque) == 0  # cleared without any consume
q.close()
assert not q._reaper_thread.is_alive()
Self-check: a topic nobody consumes from still drains; close() stops the thread.

08 Visibility timeout

consume(topic, visibility_s): don't delete — move the message into a flat _in_flight: dict[msg_id, InFlight] holding the message, its topic, and deadline = monotonic() + visibility_s. Guard it with its own lock.

Example

q = Queue8()
q.publish("t", "a"); q.publish("t", "b")
m1 = q.consume("t", visibility_s=5)   # → Message("a")
m2 = q.consume("t", visibility_s=5)   # → Message("b")   not "a" again
q.consume("t", visibility_s=5)        # → None
assert len(q._in_flight) == 2         # both hidden but alive
Self-check: a consumed message is invisible to other consumers but still tracked.

09 Ack and redelivery

ack(msg_id) -> bool removes the entry from _in_flight. Extend the reaper: any entry past its deadline is popped from _in_flight and pushed back onto the head of its topic's deque.

Example — redelivery on timeout

q = Queue9()
q.publish("t", "a")
m = q.consume("t", visibility_s=0.1)     # in flight
# consumer "dies" without acking
time.sleep(0.3)                          # reaper redelivers
m2 = q.consume("t", visibility_s=5)
assert m2.id == m.id                     # same message, again

Example — clean ack

q.publish("t", "b")
m = q.consume("t", visibility_s=5)
assert q.ack(m.id) is True
time.sleep(0.3)
assert q.consume("t", visibility_s=5) is None   # never comes back
Self-check: unacked messages return with the same id after the visibility timeout; acked ones never do.

10 Assemble the full thing

Final class MessageQueue:

publish(topic: str, payload: str, ttl_s: float) -> str        # returns message id
consume(topic: str, visibility_s: float) -> Message | None
ack(msg_id: str) -> bool
queue_size(topic: str) -> int                                 # ready deque only
close() -> None

Per-topic locks, monotonic clock throughout, lazy TTL on consume plus the reaper doing both TTL eviction and visibility redelivery, clean shutdown.

Example — stress harness with dying consumers

q = MessageQueue()
TOPICS = ("a", "b", "c")
acked = {}          # msg_id → times acked

def producer(pid):
    for i in range(1000):
        q.publish(random.choice(TOPICS), f"{pid}-{i}", ttl_s=30)

def consumer():
    while not done.is_set():
        m = q.consume(random.choice(TOPICS), visibility_s=0.2)
        if m is None:
            continue
        if random.random() < 0.9:          # 90% ack, 10% "die" without acking
            acked[m.id] = acked.get(m.id, 0) + 1
            q.ack(m.id)

# spin 4 producers + 4 consumers, wait until len(acked) == 4000

assert all(c == 1 for c in acked.values())            # each acked exactly once
assert sum(q.queue_size(t) for t in TOPICS) == 0
assert len(q._in_flight) == 0
q.close()
Self-check: every published id gets acked exactly once even when consumers die; deques and _in_flight both empty at the end; close() stops the reaper.
